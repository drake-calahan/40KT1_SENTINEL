## Règles

- **Déplacer, jamais supprimer.** Archiver = `git mv` vers ce dossier **+ un
  stub** à l'ancien chemin, pour que les liens existants ne pourrissent pas.
- Les **ADR ne s'archivent pas** : elles restent dans `docs/adr/`, et c'est leur
  **statut** qui porte la couche (Accepté / Suspendu / Sans objet / Remplacé).
- Un plan livré ou fermé va dans `archive/plans/`, avec son stub dans
  `docs/plans/README.md`.
